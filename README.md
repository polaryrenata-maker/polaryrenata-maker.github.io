## 🌐 Visite meu site

**[Abrir polaryrenata-maker.github.io](https://polaryrenata-maker.github.io/)**

Site estático e responsivo em português. Sem instalação ou compilação.

## Publicação

O GitHub Pages publica os arquivos da branch `main`, pasta `/ (root)`. As configurações ficam em **Settings → Pages**.

Documentação: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Personalizar

Edite os textos e links em `index.html`. As cores e os estilos estão em `style.css`. A página não afirma experiência profissional, formação ou habilidades não informadas. Os nomes de tecnologias na seção do projeto descrevem este site.

As fontes usam Google Fonts; se estiverem indisponíveis, o navegador usa as fontes locais de reserva.
