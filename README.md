## Projetos

### Barbosa Água e Gás

Site que desenvolvi como projeto acadêmico para um microempreendedor de São Luís — MA. A página apresenta água mineral e gás de cozinha, informa os bairros atendidos e facilita o contato pelo WhatsApp.

- Layout responsivo para computadores e celulares.
- HTML, CSS e JavaScript reunidos em um único arquivo.
- Botões com mensagens específicas para cada produto.
- Identidade visual em azul e publicação no Netlify.

**[Acessar o site](https://barbosaaguagas.netlify.app)** · **[Ver código e documentação](projetos/barbosa-agua-e-gas/)**
