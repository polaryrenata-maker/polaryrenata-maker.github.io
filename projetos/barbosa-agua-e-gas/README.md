# Barbosa Água e Gás

Site institucional para um microempreendedor de São Luís — MA que comercializa água mineral e gás de cozinha. O projeto foi desenvolvido como trabalho acadêmico, com foco em uma apresentação clara dos produtos e no contato direto pelo WhatsApp.

**[Acessar o site publicado](https://barbosaaguagas.netlify.app)**

## Autoria

Desenvolvido por **Renata Polary** como projeto acadêmico aplicado a um negócio local.

## Sobre o projeto

A proposta foi criar uma presença digital simples e funcional para o negócio: apresentar a empresa, mostrar os produtos, informar a área de atendimento e facilitar o início de um pedido.

A página foi construída em um único arquivo `index.html`, com estilos, JavaScript e imagens incorporados. Isso permite abrir o site localmente ou publicá-lo sem instalar dependências nem executar uma etapa de compilação.

## Funcionalidades

- Layout responsivo para computadores e celulares.
- Apresentação dos produtos: água mineral e gás de cozinha.
- Botões de WhatsApp com mensagens específicas para cada produto.
- Lista de bairros e localidades atendidos em São Luís.
- Contato por WhatsApp e por telefone.
- Menu de navegação para dispositivos móveis.
- Animações discretas, com respeito à preferência por movimento reduzido.
- Recursos de acessibilidade, como link para pular ao conteúdo, identificação dos controles e navegação do menu por teclado.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.

Não é necessário instalar pacotes. Os links de WhatsApp precisam de conexão com a internet para abrir o atendimento.

## Decisões de implementação

O contato acontece diretamente pelo WhatsApp, sem formulário ou banco de dados. As mensagens já indicam o produto de interesse, e o visitante pode conferir a área de atendimento antes de entrar em contato.

A identidade visual utiliza azul como cor principal, referências à água e ao gás e verde nos botões de WhatsApp. Os elementos visuais ficam incorporados ao HTML para preservar a proposta de um site entregue em arquivo único.

## Validação

Foram conferidos os destinos dos links internos, os números e mensagens dos links de WhatsApp, a sintaxe do JavaScript e o comportamento de abertura e fechamento do menu em uma verificação automatizada. A conferência visual em navegadores e dispositivos faz parte da revisão de publicação.
